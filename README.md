# Age Detection Using Person Image

## Overview

This project predicts the age range of a person from facial images using Deep Learning and Computer Vision techniques.

## Features

* Real-time webcam age detection
* Face detection using OpenCV DNN
* Age range classification
* CNN-based prediction model
* UTKFace dataset integration

## Technologies Used

* Python
* OpenCV
* NumPy
* Deep Learning
* Convolutional Neural Networks (CNN)

## Dataset

UTKFace Dataset

## Age Categories

* 0-2
* 4-6
* 8-12
* 15-20
* 21-24
* 25-32
* 38-43
* 48-53
* 60-100

* Smart Surveillance Systems
* Access Control
